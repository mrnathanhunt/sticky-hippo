# Sticky Hippo

Unofficial $HIPPO meme site. Not the sticker shop.

## Cloudflare Pages

1. Workers & Pages → Create → Connect Git → `mrnathanhunt/sticky-hippo`
2. Build command: `npm run build:cf`
3. Output directory: `dist`
4. Custom domain: `stickyhippo.com`
